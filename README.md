# Smart-Calc-Hub

Free online calculators for everyday maths, money and health, plus a multi-language math formulas library (فارمولا) with a built-in solver.

## How to publish on GitHub Pages

1. Upload all files to the repository ROOT. The main page must be named exactly `index.html`.
2. Go to Settings → Pages → Source: Deploy from a branch.
3. Choose Branch: `main`, folder: `/ (root)`, then click Save.
4. Wait 1-2 minutes. Your site link will appear at the top of the Pages screen.

## Files

- `index.html` - main website (calculators and formulas)
- `privacy.html` - Privacy Policy
- `about.html` - About Us
- `contact.html` - Contact Us
- `404.html` - page shown for wrong links
- `.nojekyll` - tells GitHub Pages to serve the files as they are
